Decision Agent

Two deterministic policies read the published evidence matrix. D2M turns a deployment profile into a detector portfolio — or abstains when the evidence is too thin. M2B turns a new detector into a budgeted evaluation plan. Everything is computed in your browser from the same knowledge base as the paper; the optional language model only puts the result into words, it never changes it.
